# SCU: South Coast University

A single-player Nigerian university life simulator for mobile browsers.
Live in a hostel, attend lectures, take exams, hustle, build businesses and make choices that follow you.

## Files
- `index.html` : page structure
- `styles.css` : all styling
- `game.js` : all game logic (3D rooms and map use Three.js from a CDN)

## Run locally
Open `index.html` in a browser (needs internet for the 3D library).

## Play online
Enable GitHub Pages (Settings > Pages > Deploy from a branch > main > /root).

Progress is saved in your browser (localStorage) for the site address you play on.
